## Project Description
This project is a command-line application developed using Python. It uses the Caesar Cipher algorithm to encrypt and decrypt text.

## Encryption Algorithm
Caesar Cipher is a substitution encryption technique that shifts letters of the alphabet by a specified number of positions.

## Features
- Encrypts plain text.
- Decrypts encrypted text.
- Allows the user to choose a shift value.
- Runs in the command-line terminal.

## How to Run the Program
1. Open the terminal.
2. Run the command:

   `python3 main.py`

3. Follow the instructions displayed on the screen.

## Example
**Original Text:** HELLO WORLD

**Shift Value:** 3

**Encrypted Text:** KHOOR ZRUOG

**Decrypted Text:** HELLO WORLD
